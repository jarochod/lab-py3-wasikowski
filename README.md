# 🐍 Python 3 Lab – `lab-py3-wasikowski`

This repository contains source code, exercises, and projects developed while completing the **"[2026] Kurs Python 3 od Podstaw do Mastera"** course by **Arkadiusz Wąsikowski**. 

The goal of this repo is to document my progress and build a solid foundation in Python — ranging from absolute basics to advanced software engineering concepts.

---

## 🛠️ Topics & Technologies Covered

- **Python Core Fundamentals:** Data types, control flow, functions, lambdas, scope, and built-in modules.
- **Object-Oriented Programming (OOP):** Classes, objects, inheritance, encapsulation, magic methods, and polymorphism.
- **File I/O & Serialization:** Text (UTF-8) and binary files, `pickle`, JSON parsing, and Regular Expressions (Regex).
- **Databases & ORM:** PostgreSQL & SQLite3 integration, writing complex SQL queries/procedures/triggers, and ORM mapping with **SQLAlchemy** (1:1, 1:N, N:M relations).
- **GUI Development:** Desktop applications built using **Tkinter**, **PySide**, **wxPython**, and **Turtle**.
- **Web Applications & APIs:** Full-stack web apps using **Flask** (Jinja2 templates, WTForms, Flask-Login) and REST API integration via `requests`.
- **Web Scraping & Automation:** Data extraction using **BeautifulSoup4**, **Selenium**, and **Playwright**.
- **Multithreading:** Concurrency handling using `_thread`, `threading`, and thread synchronization.
- **Testing & Quality Assurance:** Unit testing with **`unittest`** (mocking, setup/teardown) and **`pytest`** (fixtures).
- **Design Patterns & Architecture:** Hands-on implementation of GoF patterns (Factory, Singleton, Builder, Observer) and architectural patterns (Repository, DAO, DTO, Event Sourcing, EAV).
